# Simple Calculator

A simple command-line calculator built using Python. This project performs basic arithmetic operations through a terminal-based menu.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Clear option
- Exit option
- Repeated calculations
- Invalid choice handling
- Invalid number input handling
- Division by zero handling

## Technologies Used

- Python 3
